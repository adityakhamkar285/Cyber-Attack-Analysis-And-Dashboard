🚨 Cyber Attack Dashboard
A dynamic and interactive dashboard built to analyze, monitor, and visualize cyber attack patterns across different regions, attack types, and time periods.
📊 Key Features
* Real-time attack insights
* Attack type distribution (Malware, Phishing, DDoS, etc.)
* Region-wise threat analysis
* KPI cards for total attacks, risk level, and trends
  
📈 Insights Generated
* Identified high-risk regions and attack-prone areas
* Detected sudden spikes in cyber threats
* Highlighted critical security risks
